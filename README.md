# Trilobit

A turn-based cyberpunk roguelike in Godot 4.3 (GDScript). The game lives in [`godot-spike/`](godot-spike/); see its README and PLAN.

This repository began as a fork of Cataclysm: Dark Days Ahead. All CDDA game source, stock data and the CDDA-side Trilobit mod have been removed from the tree (they remain in git history before the `remove-cdda` branch). The item and art generators the Godot build needs now live in `godot-spike/tools/content/`, and the gun table in `godot-spike/data/source/gunset.json`.

`LICENSE.txt` is kept because content derived from CDDA (CC BY-SA 3.0) is still in the history and in some generated data.
