HOW TO USE (Notepad is fine)
1. Open _CORE_RULES.txt, and the prompt you need (1 gameplay, 2 visuals,
   3 quests).
2. In the prompt, replace the line "[PASTE THE FULL TEXT OF _CORE_RULES.txt HERE]"
   with the contents of _CORE_RULES.txt.
3. Fill in the FILL-IN fields. Leave a field blank to let Claude use the
   Defaults rule. Delete the lines that start with "#".
4. Paste the whole thing into a new Claude session on this project.
5. Claude works alone and returns a short report. Check the "Defaults I
   chose" and "Needs Eric" lines; override anything by sending a short reply.
When a rule changes, edit _CORE_RULES.txt first, then update the pasted copy.
